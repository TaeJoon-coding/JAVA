문) 아래에 제시된 UML 다이어그램 설계도를 참조하여, 이전 문제에서 작성되었던 CalcClass를 활용하는 클래스를 작성합니다.

작성 요령)

1. 우선 UML 다이어그램에 제시된 패키지와 클래스 명세를 참고하여 클래스를 작성합니다.

2. 멤버 필드의 경우에 ▲ 이라는 기호는 Amateras UML 툴에서는 default 접근 제어자를 의미하며, 이 접근 제어자는 무표기(표기 하지 않음)로 처리합니다. 

calcClass : CalcClass 의 의미는 멤버 필드명과 자료형을 의미합니다. 멤버 필드 정의(작성)시 CalcClass 클래스의 생성자를 활용하여 바로 
인스턴스가 생성될 수 있도록 초기화합니다.

3. calc 메서드의 경우는 아래와 같이 쓰일 수 있도록 정의합니다. 쓰임새를 확인하여 유추한다면 첫번째 인자는 연산자가 들어가게 되며(이것으로써 연산의 종류를 결정), 두번째, 세번째는 각각 연산되는 숫자가 들어갑니다. 또한 아래와 같이 화면에 출력(System.out.println)이 된다는 것은 메서드에 숫자형의 리턴값이 있다는 것인데, 실제로 설계서상 리턴 자료형은 int 자료형입니다.

예) System.out.println(calcUse.calc("+", 1, 2));

4. 메서드 코드 내부(몸통:body) 구성은 일단 연산자(문자열 성분)를 switch ~~~ case문을 활용하여 각각 연산자 기호별로 CalcClass에서 
해당 사칙연산 메서드를 호출하도록 조치합니다. 이때, 메서드 호출시 필요한 인스턴스는 2번 과정에서 생성된 calcClass 인스턴스를 활용합니다. 
 또한 연산자가 사칙연산에 해당되지 않는 다른 기호라면 기본값(default)을 덧셈으로 연산할 수 있도록 조치합니다.

5. main 메서드를 아래와 같은 내용으로 작성합니다.

CalcUse calcUse = new CalcUse();
System.out.println("덧셈의 결과 : "+ calcUse.calc("+", 1, 2));
System.out.println("뺄셈의 결과 : " + calcUse.calc("-", 2, 1));
System.out.println("곱셈의 결과 : " + calcUse.calc("*", 2, 3));
System.out.println("나눗셈의 결과 : " + calcUse.calc("/", 4, 2));
System.out.println("나머지 연산의 결과 : " + calcUse.calc("%", 3, 2));
